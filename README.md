An interactive 3D web application designed for **Elite Grill**, a premium restaurant. Features custom 3D WebGL GLTF model rendering (`chicken_hero.glb`), interactive menu showcases, and responsive dining reservation interface.

---

## 🌟 Key Features & WebGL Architecture

- **Custom 3D GLTF Model Rendering:** Embedded 3D model canvas (`chicken_hero.glb`) with custom WebGL lighting, orbit controls, and camera placement.
- **Interactive Food Catalog:** Categorized menu grid with item cards, pricing, and visual meal previews.
- **Zero Heavy Framework Overhead:** Pure HTML5, CSS3, JavaScript, and Three.js canvas rendering.
